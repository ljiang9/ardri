# Ardri 威尔士跳棋

极简 tafl 类不对称围歼棋：攻方 16 子围杀，守方 8 子护王突围。纯 Python 标准库，无第三方依赖。

## 玩法

- 7×7 棋盘，王（王）开局在中央王座（○），8 守子环绕，16 攻子分布四边。
- 攻方先走，双方轮流走子：横/竖走任意格（车式走法），不可跳子、不可斜走。
- **夹吃**：走子后若某敌子被夹在你的两子之间（或一子 + 空王座），该敌子被移除。王不能被普通夹吃。
- **胜负**：王到达任意边缘格 → 守方胜；王被四面围住（四邻全是攻子，空王座也算敌对）→ 攻方胜。
- 只有王可以占据/经过王座；400 半回合未分胜负判和棋。

## 运行

```bash
python3 -m ardri                 # 人机对战（默认执守方）
python3 -m ardri --side A       # 执攻方
python3 -m ardri --auto --games 10 --seed 42        # AI 对 AI
python3 -m ardri --auto --games 10 --seed 42 --verbose
```

走法输入 4 个数字：`起始行 起始列 目标行 目标列`（0–6），`q` 退出。

图例：`攻` 攻子 / `守` 守子 / `王` 王 / `·` 空格 / `○` 空王座。

## 设计取舍与诚实局限

- **规则是重构的**：Ardri 原始规则已失传，本项目采用常见 tafl 重构（7×7 / 王到边缘胜 / 四面围王），不可当正史规则。
- **AI 很弱**：只是 1 步贪心启发式（王离边缘距离、王身边攻子数、子力），不做深层搜索；熟悉棋理的人类通常能赢。演示中守方占优是弱 AI 的产物。
- 文本回合制，无图形界面/存档/悔棋；Python 3.10+。
